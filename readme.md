Veda Technology Business & Service Management System

1. Project Description

A Python-based application designed to manage digital services, technology programs, internship programs, customers, and customer inquiries. It provides options to add, view, search, update, delete, and filter records.

2. Objectives

- Apply Python programming concepts to a practical business scenario.
- Manage services, programs, customers, and inquiries.
- Implement search and filtering functionality.
- Generate basic business summary reports.
- Store records using JSON file handling.

3. Technologies Used

- Python
- JSON
- Lists and Dictionaries
- Functions and Conditional Statements
- File Handling
- Visual Studio Code

4. Key Features

- Add digital services and technology programs.
- Manage internship program records.
- Add and manage customer details.
- Record customer inquiries and their status.
- View, search, and filter records.
- Update and delete existing records.
- Generate business summary reports.
- Save records in a JSON file for future use.

5. Project Files

- "business_management.py" — Main Python application.
- "business_data.json" — Automatically created file for storing records.
- "README.md" — Project documentation.

6. How to Run

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run the following command:

& "C:\Users\Admin\.local\bin\python3.14.exe" business_management.py

No external Python libraries are required.

7. How to Use

1. Run the program.
2. Select an option from the menu.
3. Enter the required record details.
4. View, search, or filter records.
5. Update or delete records when necessary.
6. Generate the business summary report.
7. Select Exit to close the application.

8. Data Storage

The application stores information in "business_data.json". Saved records are loaded automatically when the program starts, allowing data to remain available between sessions.
